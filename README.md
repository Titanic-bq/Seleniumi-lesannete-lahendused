# Seleniumi kodutöö

## Autor
Hendrik Jürgenson

## Kirjeldus

Selles projektis on Seleniumi abil tehtud  ülesanded.
Ülesannete käigus õppisin kasutama Pythonit ja Selenium WebDriverit
veebilehtede avamiseks, elementide leidmiseks, klõpsamiseks,
vormide täitmiseks ja tulemuste kontrollimiseks.

## Ülesanded

### Ülesanne 1 – Google'i otsing
- Avab Google'i
- Leiab otsingukasti
- Sisestab nime "Hendrik Jürgenson"
- Teeb otsingust screenshot'i

### Ülesanne 2 – Tsitaadid
- Avab Quotes to Scrape veebilehe
- Leiab kõik esimese lehe tsitaadid
- Leiab tsitaatide autorid
- Kuvab need terminalis

### Ülesanne 3 – Add/Remove Elements
- Avab Add/Remove Elements lehe
- Vajutab "Add Element" nuppu 5 korda
- Leiab loodud Delete nupud
- Kustutab kõik elemendid

### Ülesanne 4 – Login
- Avab login-vormi
- Sisestab kasutajanime ja parooli
- Vajutab Login
- Kontrollib, kas sisselogimine õnnestus

### Ülesanne 5 – Checkboxes
- Avab Checkboxes lehe
- Märgib mõlemad checkboxid
- Kontrollib nende olekut
- Liigub tagasi eelmisele lehele

## Failid

- `task1.py` – Google'i otsing
- `task2.py` – tsitaatide leidmine
- `task3.py` – elementide lisamine ja kustutamine
- `task4.py` – login-vormi test
- `task5.py` – checkboxide test
- `screenshots/` – ülesannete screenshot'id
